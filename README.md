# Linux System Administration Lab

A beginner-friendly, hands-on Linux System Administration project designed to develop practical skills in Linux administration, system management, automation, and troubleshooting using Ubuntu Server.

## Project Objectives

- Learn Linux command-line operations
- Manage users and groups
- Configure file permissions and ownership
- Install and manage software packages
- Monitor and manage processes
- Configure and manage system services
- Set up SSH for remote administration
- Automate tasks using Cron jobs
- Perform network diagnostics and troubleshooting
- Manage disks and file systems
- Create Bash scripts for system administration
- Solve real-world Linux troubleshooting scenarios

## Technologies Used

- Ubuntu Server 24.04 LTS
- Bash Shell
- Linux Command Line
- OpenSSH
- APT Package Manager
- Git & GitHub

## Skills Demonstrated

- Linux System Administration
- User & Group Management
- File Permissions
- Package Management
- Process Management
- Service Management
- SSH Administration
